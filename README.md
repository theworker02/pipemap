# pipemap

Pipe and reshape map text streams with deterministic transforms.

**Site:** https://theworker02.github.io/pipemap/

## Install / run

```bash
git clone https://github.com/theworker02/pipemap.git
cd pipemap
node src/cli.js
node --test
```
